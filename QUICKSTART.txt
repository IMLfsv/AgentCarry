AgentCarry 0.4 实验版 · Windows x64

下载后怎么用

1. 将整个 ZIP 解压到任意普通目录。保留 _internal 文件夹，不要只复制 EXE。
2. 双击 AgentCarry.exe。无需安装 Python，无需 API Key。
3. 在“选择内容”中读取 Codex 项目，勾选项目和会话。
   也可打开另一台电脑导出的 private-job/job.json，迁移包整个目录须一并复制。
4. 选择迁移方式和输出目录。输出目录不能与源项目重叠。
5. 点击“准备并检查迁移”，阅读报告。
6. 原生模式检查通过后，点击“执行导入”，然后启动 Antigravity 验证。

项目目录：输出目录/workspaces
迁移包、报告和备份：输出目录/runs

选择原生导入时

目前原生适配为 Windows Antigravity App 2.32.2 的已验证安装版本。
先完全退出 App 和后台进程；不同版本会明确拒绝写入。
如果退出后仍提示数据库日志残留，可使用“整理数据库”，会先保存备份。

用户/助手的文字进入原生会话。历史工具调用和图片等当前只保留在迁移档案中，
需阅读报告并勾选“接受转换差异”后重新准备。原标题会保存，但客户端可能显示
首条消息；原生消息时间重新生成。完整无损原生迁移仍未完成。

导入后检查：能继续对话，能找到新项目文件，重启 App 后会话及新回复仍保留。
本版批量流程经过隔离测试，真实客户端只验证过一个短文本案例；尚未经过多用户
不同电脑的运行验收。请将本版视为公开测试候选，不代表所有历史和版本兼容。

可移植模式

支持恢复项目文件、对话档案和已收集附件，可在其他工具打开 project/ 继续工作。
此模式不向目标软件的原生聊天列表注册记录。

恢复原生导入

在“检查并执行”中选择“恢复一次导入”，选择该次 runs/.../plan/plan.json。
原生数据恢复前会检查后续修改；有续聊或其他变更时拒绝覆盖。项目文件保留。

隐私

全部迁移在本机进行，不上传项目或聊天。迁移包、计划、备份都是私有数据。
不要把它们上传到公开 GitHub 仓库；文件名排除不代表内容已经脱敏。

源码运行与构建

源码入口：python app.py
测试：python -m unittest discover -s tests -v
Windows x64 构建：安装 requirements-build.txt 后，运行
python build_release.py --out 一个尚不存在的构建目录

独立程序自检（只生成临时合成数据，不读取实际聊天）：
AgentCarry.exe --self-test --report 一个尚不存在的报告文件.json
AgentCarry.exe --smoke-gui --report 另一个尚不存在的报告文件.json

更多细节见 README.md、ACCEPTANCE.md 和 VALIDATION.txt。
